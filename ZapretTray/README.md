
# Zapret Tray

Небольшой Windows-тогглер в системном трее для службы `zapret` из сборки `zapret-discord-youtube`.

## Возможности

- Показывает статус службы: зелёный — запущена, серый — остановлена.
- Контекстное меню: включить, выключить, переключить, выйти.
- Переключатель автозапуска для текущего пользователя Windows.
- Запрашивает UAC только при смене состояния службы.
- Не изменяет стратегию zapret, Karing и сетевые правила.

## Запуск

Дважды щёлкните `Start-ZapretTray.vbs`. В области уведомлений появится значок. Если он скрыт, откройте меню `^` возле часов.

Для автозапуска откройте меню значка и включите «Запускать вместе с Windows». Это создаст ярлык `Zapret Tray.lnk` только в пользовательской папке Startup.

## Требования

- Windows PowerShell 5.1 или новее.
- Установленная служба с именем `zapret`.
